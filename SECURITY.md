# Security Policy

## Report a vulnerability

If you find a vulnerability in `which-nuxt`, report it privately. Do not open a public issue.

- Use [GitHub private vulnerability reporting](https://github.com/harlan-zw/which-nuxt/security/advisories/new).
- Or email harlan@harlanzw.com.

Include the affected version, steps to reproduce, and the impact.

A vulnerability in a site that `which-nuxt` scans belongs to that site's owner or to the affected Nuxt package, not here.
